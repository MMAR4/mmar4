## 🚀 Featured Project

### Airbnb End-to-End Data Engineering Pipeline

An end-to-end pipeline that uses AWS S3, Snowflake, and dbt Core to transform Airbnb bookings, hosts, and listings data into analytics-ready models.

- Implemented Bronze, Silver, and Gold transformation layers.
- Built incremental models and reusable Jinja macros.
- Used dbt snapshots with SCD Type 2 to track historical changes.
- Developed fact and dimension tables, along with a One Big Table (OBT).
- Added data quality tests for transformed datasets.
