## 👨‍💻 About Me

I'm a Computer Science Engineering graduate interested in **Data Engineering, cloud data platforms, and scalable data processing**.

I enjoy transforming raw datasets into structured, analytics-ready information and building data workflows using modern data engineering tools.

My technical interests and practical experience include:

- **Data Pipelines:** ETL/ELT workflows, data ingestion, and transformation.
- **Cloud Data Engineering:** Snowflake, AWS S3, and dbt Core.
- **Big Data Processing:** Databricks and PySpark.
- **Data Modeling:** Fact and dimension tables, Medallion Architecture, and SCD Type 2.
- **Data Analytics:** SQL, Python, and Power BI for data analysis and visualization.

I continue to strengthen my skills through hands-on projects and practical learning.
